# Колледж Помощник

Telegram-бот с расписанием, объявлениями, контактами и ответами на частые вопросы. Студент выбирает группу при первом запуске. Преподаватель может написать своим группам и ответить на вопросы студентов.

При выборе группы можно нажать кнопку или написать название группы из списка. Чтобы посмотреть расписание на конкретный день, отправьте дату, например `12.11` или `12.11.2026`. Если год не указан, бот использует текущий год по часовому поясу колледжа.

## Запуск через Docker

1. Создайте бота в [@BotFather](https://t.me/BotFather) и получите токен.
2. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN` и `ADMIN_ID`. В `ADMIN_ID` укажите числовой Telegram ID администратора.
3. Если нужны преподаватели, сопоставьте их Telegram ID со списками групп в `TEACHER_GROUPS`. Используйте названия из заголовков расписания.

   ```dotenv
   TEACHER_GROUPS='{"123456789":["СВ-21","СВ-22"],"987654321":["ИС-11"]}'
   ```

4. Запустите Docker Desktop или Docker Engine. Соберите контейнер и откройте журнал.

   ```sh
   docker compose up -d --build
   docker compose logs -f bot
   ```

5. Откройте бота, нажмите `/start` и отправьте `/admin` с аккаунта администратора. Загрузите расписание, чтобы группы появились в меню. Преподаватели и студенты тоже должны нажать `/start`, чтобы получать сообщения от бота.

В контейнере бот работает через long polling. Для одного токена держите один экземпляр. По умолчанию «Сегодня», «Завтра» и «Неделя» считаются по `Asia/Almaty`. Часовой пояс можно поменять в `COLLEGE_TIMEZONE`. Неделя начинается в понедельник.

## Загрузка расписания

Администратор отправляет `/import` и прикрепляет файл `.xlsx` или `.csv` как документ.

- Для Excel с сеткой колледжа бот читает заголовки групп, номера недель и интервалы дат. Если на пару приходятся несколько занятий, в расписании появляются все записи. После импорта бот указывает ячейки с пересечениями и занятиями вне недель, указанных в заголовке группы.
- Для CSV и обычного Excel используется следующая таблица. В CSV можно разделять поля запятыми или точками с запятой. Подойдут UTF-8 и Windows-1251.

  ```csv
  date,group,period,starts_at,ends_at,subject,room,teacher
  2026-11-16,СВ-21,1,08:00,09:20,Информатика,506,Иванов И. И.
  2026-11-17,СВ-21,,,,,,
  ```

Файл заменяет расписание для указанных групп и дат. В сетке даты берутся из заголовка листа. В таблице строка с датой и группой и пустыми остальными полями обозначает день без занятий. Если в файле есть ошибка, бот указывает строку или ячейку и сохраняет действующее расписание.

## Команды

| Команда | Действие |
| --- | --- |
| `/start` | Выбор группы и вход в меню |
| `/send` | Рассылка преподавателем по своим группам. Администратор может выбрать любую группу или всех |
| `/admin` | Список команд администратора |
| `/import` | Загрузка расписания |
| `/contacts`, `/faq` | Добавление, редактирование и удаление записей |
| `/stats` | Число пользователей всего и по группам |
| `/cancel` | Отмена текущего действия |

Рассылка уходит после подтверждения. Бот сохраняет её в объявлениях и по окончании показывает число доставленных сообщений. Если контейнер перезапустится, очередь продолжит отправку ожидающих сообщений. Для сообщений, которые были в отправке в момент остановки, бот укажет, что доставку не удалось проверить.

Кнопка «Задать вопрос» отправляет текст преподавателю группы. Если преподавателя нет или ему невозможно отправить сообщение, вопрос получает администратор. Ответ приходит в тот же чат с ботом.

## База и резервные копии

SQLite, журнал и резервные копии хранятся в томе `college-data`. Первую копию бот создаёт при запуске, затем обновляет резервные копии раз в неделю. Файлы лежат в `/var/lib/college-bot/backups`.

Чтобы сохранить копии на компьютере, скопируйте их из контейнера.

```sh
docker compose cp bot:/var/lib/college-bot/backups ./college-backups
```

Для остановки используйте `docker compose down`. Флаг `-v` удаляет том вместе с базой, журналом и копиями.

## Запуск без Docker

Нужен Python 3.12. Заполните `.env`, как при запуске через Docker.

```sh
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
# Linux или macOS
# source .venv/bin/activate
python -m pip install -r requirements.txt
python -m college_bot
```

При локальном запуске файлы базы хранятся в `data/`. Путь можно изменить в `DATA_DIR`.

## Тесты

```sh
python -m unittest discover -s tests -v
```

Тесты используют временную базу и заглушку Telegram API.
